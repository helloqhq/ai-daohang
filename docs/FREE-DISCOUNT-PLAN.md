# 免费、折扣面板与采集范围扩展

状态：2026-10-16 两轮设计已全部确认，本地实现与验证完成。发布状态以独立 GitHub Pages 部署记录为准。

## 已确认

- 新增“免费模型”“折扣模型”渠道信息面板，覆盖模型 API、聊天产品和 Agent 套餐，方便快速筛查。
- 折扣可收录渠道促销、相对原厂价格优势、非高峰和 Batch 等优惠；分别展示优惠类型、比较基准和适用条件。没有可靠比较基准时只展示价格，不计算折扣。
- 保留“模型厂商 / Agent / 平台 / 名人”四个一级分类，自动补充其中的对象。Agent 范围包含应用、运行工具和开发框架，以子类型区分。
- 自动扩充仅纳入与 AI 强相关且影响力有依据的对象。依据可核实的实际采用、技术贡献或行业影响，记录入选理由；粉丝数仅作辅助。人物优先包括能提供 AI 一手信息的负责人、研究者和重要项目作者。
- 每次调用 ai-news-collect 时自动发现、核实并加入满足标准的对象；证据不足者保留为候选。允许补充官方信源、修复订阅地址；失效来源保留记录和原因。
- 自动完善、优化的范围包括“计费方案”的对象与信源，不仅是动态关注名单。

## 实施前的现状

- 计费页已有 API、Token Plan 和 Agent 类别；免费、折扣条件尚未结构化，现有备注不足以直接形成可靠筛选。
- 现有“免费”同时包含工具无订阅费和附带模型额度，两者需要明确区分。
- 计费目录独立于动态快照；新闻材料统一经 RSS/Atom 获取，计费目录现有流程核验官方定价页。
- 各方案分别记录核验日期，现有规则为超过 30 天提示重新核验；有明确截止日期的活动到期后有过期标识。
- 本机安装技能是仓库 skills/ai-news-collect 的符号链接，编辑仓库技能即更新本机技能。

## 第二轮确认

- 免费面板收录持续额度、注册赠送、试用和限时免费，标明额度、刷新、资格、绑卡和期限；仅客户端免费而推理另计的工具不计入免费模型。
- 同一共享套餐只有一条记录，以适用场景进入聊天与 Agent 筛选；入口停服不等于整个套餐停服。
- 技能同次维护计费对象与信源，并核实更新价格、模型权益、免费额度和折扣。可读官方定价与条款；新闻继续通过 RSS/Atom 入队，分别记录覆盖。
- 快捷面板默认排除到期、暂停、待核验、尚未开始以及超过 30 天未核验的优惠；保留另行查看入口。官方确认有效但未公布截止日的优惠可收录并明确标注；分时优惠写明时段。
- 计费页顶部设置免费、折扣两个面板，显示可用方案数量，点击后与类别、厂商、币种和关键词筛选组合使用。

后续界面调整：两个入口改为同排的紧凑按钮，仅显示名称与数量；移除卡片英文眉题、长说明和重复操作文案，保留选中状态与筛选行为。

## 实施约定

免费与折扣使用每个方案的 offers 数组，核验、期限及比较基准分别记录；具体契约见 [PRICING.md](PRICING.md)。共享套餐使用 use_cases，不复制方案。面板计数按方案去重，不把优惠数量称为模型数量。

首批结构化记录仅整理现有目录已核实的事实，保留原日期；不以此宣称执行了新一轮线上采集或覆盖全部渠道。未纳入的免费／优惠类型由后续技能调用按证据逐步补齐。

## 同步范围

已同步术语、计费数据契约与校验、前端双语展示、采集技能及其引用、关注对象和来源配置的校验、相关流程文档。保留稳定标识、历史引用和覆盖缺口，不把来源登记当作采集成功。沿用采集与发布分离的流程。

## 验证

- npm test：54 项 Python、47 项 JavaScript 测试通过，覆盖优惠期限、价格维度可比性、旧证据失效、共享套餐、免费 API 与客户端免费区分、配置引用及证据完整性。
- npm run pricing:build、npm run build：通过，计费 RSS 与预渲染均包含优惠信息，新闻历史仍为 229 条。
- 技能 quick_validate：通过；独立子代理在隔离目录前向试用，实际校验分时 Credits 折扣及缺年份的待核验活动记录，合成数据未上线。
- 浏览器验证中英文、组合筛选、优惠类型、不可用记录开关及 390px 移动端；价格页自动可访问性检查零违规，颜色对比度仍有一组屏外表格需人工判断的未完成检查，不等于完整无障碍认证。
- 本地目录检查无计费对象与动态来源映射缺口；不代表重新核实了线上价格。未执行新一轮新闻采集、发现登记或全目录线上复核。
