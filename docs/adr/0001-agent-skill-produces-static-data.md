# AI agent 通过采集 skill 生成静态网站数据

本站面向用户本人及 AI 开发者，采用免费静态托管；用户通过已有 AI agent 调用专用采集 skill，完成来源采集、筛选、中文加工并统一生成 JSON。JSON 约束适用于网站消费的数据，不限制上游原始格式；这一选择允许接入官方网页、RSS 和项目发布记录，也使网站无需常驻后端或直接调用 AI 模型。

相较于站外常驻采集服务或网站实时加工，这一方式复用用户已有的 agent 能力，但网站的新鲜度取决于 agent 的实际调用和数据发布。后续讨论确认首版按需调用，首次采集最近 3 天；采集 skill 只更新并验证项目内 JSON，网站发布独立执行，定时调用留待以后。

方案修订要求采集、解析、缓存和校验优先复用脚本，agent 只处理新增或实质变化材料的语义筛选与中文加工，减少重复上下文和重复推理。YouTube、TikTok、X、微信公众号作为来源平台接入同一配置和适配框架；实际读取能力与证据范围分别记录，受限渠道不被描述为完整覆盖。
