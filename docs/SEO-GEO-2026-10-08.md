此前本地 Search Console 索引核验记录确认首页可索引，邮件中的三个旧站路径应保留真实 404。本轮没有重复请求 Google 索引、提交站点地图或宣称历史排除项已经清零。

本轮落地三项修改：

1. `public/assets/render.js` 在现有动态卡片上添加 NewsArticle microdata：标题、摘要、实际显示语言、来源发布日期、内容类型和原始来源链接。构建预渲染与浏览器交互继续共用同一渲染函数，因此英文切换、中文回退、筛选和分页不会遗留一份与页面不符的静态标记。未知日期不补造时间，不把厂商或负责人登记为本站摘要作者，不添加不存在的评分、FAQ 或图片。
2. `scripts/build_seo.py` 从公开 HTML 的 canonical 自动生成发布目录的两种 sitemap。`lastmod` 来自相关页面、共享资源及首页数据的 Git 修改记录；本地未提交文件使用其修改时间。未修改内容的重复构建及无关文档提交不会刷新日期。GitHub Actions 获取完整历史；无 Git 的源码副本沿用已有 sitemap 日期。源目录 XML 保留为本地预览与无 Git 回退，**部署产物以 dist 中生成的 XML 为准**。
3. `scripts/indexnow.py` 和 `public/indexnow-key.txt` 接入 IndexNow。GitHub Pages 部署成功后，从部署前后差异选出受影响的规范页面，先核对已上线的根目录验证文件，再 POST 更新通知。首次或手动部署通知全部规范页面；无网页变化则跳过。验证文件暂不可读时最多重试三次，只重试读取，不重复发送 POST；通知失败在工作流中可见，但不回滚成功部署。公开验证文件不是账号登录密钥。

可本地预览通知内容：

```sh
python3 scripts/indexnow.py --dry-run
```

手动通知应在当前构建部署后执行 `python3 scripts/indexnow.py`；部署前验证文件检查会阻止发送。通知只包含本站规范网页，不提交 JSON、筛选参数、页面片段或已失效的历史路径。HTTP 200 表示收到 URL；HTTP 202 表示收到 URL、验证待处理；二者均不代表已经索引。Google 不使用这条 IndexNow 通知，继续通过 robots、sitemap 与站内链接发现内容。

验证结果：

- 全量 47 个 Python 测试、34 个 JavaScript 测试通过，包括验证文件暂不可读的重试测试。
- `npm run build` 成功，保留 94 条事件、68 项计费方案；首页预渲染仍为近 7 天的前 18 条动态。
- 修改前后同尺寸首页截图 SHA-256 均为 `5c04eed1c5ab3d89bf01c7b837afe1da3aa204e097b478c8ea0db7262f029e22`，画面完全一致；CSS 未修改。
- 浏览器验证英文卡片的结构化标题、摘要、语言、日期和引用与正文一致；Codex 搜索正常，计费表仍显示 68 项方案，无浏览器错误；未经统计同意时 Google 脚本请求为 0。
- sitemap XML 可解析，仍只包含现有五个规范页面；无过滤参数或 `/en/` 历史路径。
- 部署前 IndexNow 只做 dry-run 和隔离单元测试，未向真实接口发送更新通知。实际回执及搜索引擎重新抓取需要部署后验证。

发布后应先确认验证文件和两种 sitemap 返回 200，再检查工作流的 IndexNow 回执。之后用 Google 的新抓取时间、sitemap 读取时间、当前页面曝光与点击，以及 Bing 的抓取时间、Recommendations、AI Performance 引用数比较效果；不要将旧站时期的累计数据直接当作本轮增减。本轮不创建定时监控。

实现依据：[Google Article 标记说明](https://developers.google.com/search/docs/appearance/structured-data/article)、[Google sitemap 日期说明](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap)、[IndexNow 协议](https://www.indexnow.org/documentation)、[Bing AI Performance 指标说明](https://www.bing.com/webmasters/help/ai-performance-9f8e7d6c)。[Google 的 AI 搜索说明](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide)明确不要求特殊 AI schema；本轮采用与用户实际内容一致的标准标记，不承诺排名、点击或引用的提升幅度。
