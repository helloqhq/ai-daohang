# 网站阅读与交互优化方案

状态：用户于 2026-10-17 确认全部推荐方案，已完成实施。

目标：保留网站现有功能、内容与紧凑信息密度，减少重复提示，改善文字扫描、筛选反馈与手机阅读。

## 审查依据

- 已读取首页、动态渲染、计费渲染、语言与样式代码，并核对相关测试与 README。
- 已查看本地 `public/` 在 1440 × 1000 和 390 × 844 下的实际页面，包括中英文动态、展开详情、计费页及首次访问存储提示。
- 英文手机动态的 axe-core WCAG 2A/AA 检查发现 `#count-all` 对比度问题；这不是全站无障碍审计结论。
- 可读性与键盘操作参考 [Web Interface Guidelines](https://raw.githubusercontent.com/vercel-labs/web-interface-guidelines/main/command.md)，建议以本站实际内容与功能约束为准。
- 本地已有公开数据的未提交改动，本提案不修改它们。

## 已实施方案

| 优先级 | 位置与现状 | 推荐改动 | 保留边界 |
| --- | --- | --- | --- |
| P1 | 计费页同时显示双语眉题和大号宣传句，手机首个价格靠后 | 标题直接使用“计费方案 / Pricing”，缩小标题区高度；有效方案说明缩为一条 | 保留所有类别、优惠入口、筛选与方案；不默认折叠整组内容 |
| P1 | 动态快照时间在计费页也显示，容易被当成价格更新时间 | 动态快照时间仅放在动态页；计费页保留各项真实价格和模型权益核验日期 | 新闻快照不代表价格核验；不重新设置任何数据日期 |
| P1 | 动态分组、每条记录及展开后的来源标题重复完整日期 | 分组保留日期，同组列表只显示小时；日期精度事件显示“仅日期”；完整时间可由可访问文本读取 | 独立关联详情显示完整日期时间；不补造小时；中文与英文使用原有时区规则 |
| P1 | 动态摘要和长要点在桌面行宽过长，手机文本层次弱 | 保留紧凑标题列表；展开后改善段落间隔、正文行长、长标识符换行与列表层次；有明确换行的内容按段落显示 | 保留摘要、全部要点、来源、材料范围、关联与更正，不截断正文，不批量重写新闻数据 |
| P1 | 手机计费表宽 790/1040px，主要信息分散在横向区域 | 保留对照表，固定较窄的模型/档位列，优先让名称与价格同时可见；单位换行排版；实际溢出时提供横滑提示与边缘线索 | 所有列可通过触摸、键盘访问，保留跨方案比较；提示不在每个分组机械重复；明确单位不能被省略 |
| P1 | “重置筛选”实际保留日期；搜索框没有可见范围说明 | 推荐改称“清除条件”，保留当前日期；搜索提示直接写“搜索当前范围…”；历史查询标题用“动态” | 清除对象、类别、类型和关键词；日期按钮仍始终可见；不增加常驻说明段落 |
| P1 | 无结果时主要提供重置，用户可能只是日期太窄 | 按实际筛选条件提供“清除条件”及可执行的扩大日期范围入口 | 不把没有入选动态解释为已完成采集或没有重要更新；不显示隐藏的信息源入口 |
| P1 | 首访存储条在手机占据约三分之一高度，标题、英文眉题和说明层级较多 | 去掉英文眉题，标题缩为“隐私与偏好”，正文精简为“语言偏好与访问统计均可选；统计需在自定义设置中单独开启。” | 保留仅必要、允许偏好、自定义与隐私政策入口；统计仍独立授权且默认关闭；详细规则留在现有设置弹窗与隐私页 |
| P2 | “免费模型 / 折扣模型”的数字实际统计方案数量 | 显式标出“项方案”，例如“免费模型 · 4 项方案”；可简化为“免费渠道 / 折扣渠道”但需统一用词 | 不改计数算法，不把无订阅费、自备 Key 当作免费推理；共享套餐不重复计数 |
| P2 | 计费额度、资格、期限与依据长文集中堆在条件列 | 用一致的键值排版与段落间隔展示“额度 / 资格 / 截止 / 依据”，长模型名、币种、价格与计费周期分别排版 | 关键资格、限制、有效期、未知价格与核验状态保持可见；保留全部链接及价格、模型权益各自核验日期 |
| P2 | 英文手机类别换行后最后一项占满整行，计数对比度不足 | 类别按钮使用更稳定的换行布局，去掉计数透明度叠加，校正文字对比度；扩大关键操作点击区域 | 类别和数字均保留，不通过缩小文字或新增隐藏菜单换取空间 |

## 文案样例

| 当前 | 建议 |
| --- | --- |
| 把价格与用量，一起看清。 | 计费方案 |
| 最新动态（全部历史也显示此标题） | 动态 |
| 重置筛选（实际保留日期） | 清除条件 |
| 搜索变化、模型或工具 | 搜索当前范围… |
| 仅统计当前核验有效的方案，额度与限制见各项条件。 | 仅计入已核验有效的方案。 |
| 更新于 2026-10-17 14时 | 动态快照 10-17 14时（完整日期保留在可访问文本） |

中文与英文同时调整，不直接逐字翻译；占位提示、辅助标签和按钮含义保持一致。

## 不变的功能与数据含义

- 首页日期预设、自定义日期、分类、具体对象、类型、双语搜索、增量阅读、原位展开、关联事件、更正与来源材料范围全部保留。
- 中文北京时间、英文太平洋时间及 PDT/PST、跨日分组与月份按需加载逻辑保持一致；仅日期事件不补造时间。
- 计费的厂商、币种、产品类别、优惠类型、失效信息开关与共享套餐计数保留；不同类别数字不保证可相加。
- 不把 Credits 换算为 tokens，不把未知价格展示为免费，不改核验日期消除过期状态。
- `?showSources=1` 的来源入口规则、授权存储与统计行为、公开数据契约不变。
- 保持标准库静态站，无新增前端运行时依赖；构建产物不提交。
- 视频产物与采集缓存均不纳入本轮审查或修改。

## 已确认的决策

1. 保留现有深色、紧凑列表和主要信息架构，本轮只做局部整理。
2. 手机计费采用“表格 + 固定首列 + 改善横滑”，保留方案之间的比较密度。
3. 仅修改界面文案与展示排版，保留已有新闻和计费正文内容。

本轮是可逆的展示与交互整理，不新建 ADR；没有新增已达成共识的领域术语，不修改现有术语表。

## 实施后的验收

1. 检查 360、390、768、1440px 的中英文首页、长标题、长正文、计费表与存储弹窗；页面本身无横向溢出，表格独立横滑。
2. 核对各筛选、日期、空态恢复、展开、继续阅读及关联详情；语言切换后维持预期状态和正确时区。
3. 核对方案数量、全部列、价格单位、额度资格、未知价格、过期/暂停/待核验、所有依据链接；折叠仅限原有非关键信息。
4. 核对键盘操作、焦点可见性、横向表格定位与对比度；存储选择语义保持一致。
5. 运行相关行为测试、`npm test` 与 `npm run build`；必要的新测试仅覆盖改变的交互和确有回归风险的行为。
6. 对照优化前后截图，动态默认列表不因装饰或额外说明降低信息密度，计费首屏更早显示实质内容。
