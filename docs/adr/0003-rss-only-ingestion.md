# ADR 0003：统一通过 RSS / Atom 获取信息

状态：已采纳，2026-10-03。用户在实施中明确要求统一 RSS 订阅，方便后续管理。

采集入口只读取已登记的 RSS/Atom。优先官方原生订阅；没有原生订阅时通过 RSSHub 或其他转换服务接入。平台仍分别登记官网、GitHub、YouTube、TikTok、X、微信公众号，但不为每个平台保留独立抓取器。

来源配置分开原始入口 url 与订阅 feed_url；RSSHub 基地址集中配置，来源只维护路由。提供订阅清单与 OPML 导出，网站来源页显示 RSS 地址和实际访问状态。采集 skill 不再直接抓官网、GitHub API、社交页面或整段视频；离线导入也必须是已登记订阅的 XML。

RSS 是获取方式，JSON 仍是网站接口。AI agent 继续负责重要性判断、中文加工和事件归并；首次 72 小时、按来源增量补采、缓存复用、无 token 预算、历史保留及独立发布边界保持有效。

有限 RSS 条目不能保证完整历史。读取失败、缺少日期、只有标题或无可用订阅时保留缺口及待处理状态，不猜测内容，不改用直接抓取。默认公共转换实例的访问限制如实记录；首版不因本次调整增加自建常驻服务或付费 API。

既有有效历史保留，新增信息通过统一订阅进入材料队列。后台切换订阅地址后重新验证覆盖，不能把旧入口成功进度冒充新订阅成功。该决策取代此前各格式／平台分别抓取的实施方案。
