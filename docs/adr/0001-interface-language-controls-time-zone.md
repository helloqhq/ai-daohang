# 界面时间口径随界面语言

英文界面希望读取自己时区的读者直接对照本地时间，中文读者已经按北京时间阅读；因此全站时刻型显示时间随界面语言选择时区——中文界面固定北京时间（Asia/Shanghai，UTC+8），英文界面固定美国西部太平洋时间（America/Los_Angeles，夏令时动态标注 PDT/PST），并把日期分组、「近 N 天」筛选、月份加载与快照栏时区标签统一到同一口径；页脚时钟沿用其既有行为。否定了浏览器本地时区：同一分享链接在不同设备显示不一致，静态预渲染与纯函数测试无法确定性输出；也否定了双时区并列显示：列表宽度与噪音代价不值得。边界保持不变：仅日期型字段（计费核验/更新/有效期、法律页更新日期、date 精度事件）按字面日期显示，`<time datetime>`、RSS `pubDate` 与 sitemap 保留原始时间，无 JS 的中文预渲染快照仍为北京时间，计费过期与重核验判定继续锚定北京时间（数据语义而非展示）。
